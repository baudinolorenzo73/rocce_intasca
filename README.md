# Rocce in tasca — PWA v1.2.0

Questa cartella è pronta per GitHub Pages. Non modificare la struttura delle cartelle.

## Pubblicazione rapida su GitHub

1. Crea un nuovo repository pubblico, per esempio `rocce-in-tasca`.
2. Carica **tutti i file e la cartella `photos` nella cartella principale del repository**.
3. Apri **Settings → Pages**.
4. In **Build and deployment**, scegli **Deploy from a branch**.
5. Seleziona il branch **main**, cartella **/(root)**, quindi premi **Save**.
6. Dopo alcuni minuti il sito sarà disponibile all'indirizzo:
   `https://TUO-NOME-UTENTE.github.io/rocce-in-tasca/`

## Installazione

- Android/Chrome: apri il sito, premi **Installa** oppure usa il menu ⋮ → **Aggiungi a schermata Home**.
- Computer/Chrome o Edge: apri il sito e premi **Installa** nella barra degli indirizzi o nell'app.
- iPhone/iPad: Safari → **Condividi** → **Aggiungi alla schermata Home**.

## Aggiornamenti futuri

Sostituisci i file del repository mantenendo gli stessi nomi e la cartella `photos`. L'app conserva il taccuino nel browser del dispositivo; è comunque consigliato esportare il taccuino prima di un aggiornamento importante.

La versione HTML autonoma `Rocce_in_tasca_v1.2.html` può essere scaricata e aperta senza connessione. I collegamenti esterni a Wikipedia, Mindat e alle carte geologiche richiedono Internet.
